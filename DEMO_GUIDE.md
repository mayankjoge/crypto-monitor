# Demo guide (about 5 min)
1. Start the app (live: `MOCK_MODE=0`; offline: `MOCK_MODE=1`, and point out the MOCK banner).
2. Dashboard: timestamp, search, header sorting, gainers/losers, watchlist star.
3. Click a coin: change periods, toggle SMA 7/30, note volume bars and volatility.
4. Signals: show the most-active rule, edit screen thresholds, explain that matches are not recommendations.
5. Failure handling: disconnect the network to show the stale/error banner.
6. Open Methodology and Limitations; state that Tier 3 is not implemented.
