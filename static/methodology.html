Methodology and Limitations

Back to dashboard

Data

Live prices, 24-hour volume, and market capitalization come from CoinGecko's public API (/coins/markets, /coins/{id}/market_chart). The app validates response shapes and numeric values, drops malformed or duplicate rows, and shows missing optional metrics as “n/a”. Market and history responses are cached. If a refresh fails, cached values are shown with a stale warning; without a cache, the app shows an error rather than inventing a price.

CoinGecko automatically selects chart-data granularity on the public API. For shorter ranges this may be hourly, so the app samples the last available observation for each UTC day before calculating daily moving averages and volatility. It fetches an additional warm-up window so SMA 7 and SMA 30 can be calculated correctly for the displayed dates. In mock mode, all market values are synthetic and clearly labelled.

Indicators

  • SMA(n): mean of the most recent n daily observations. The average is based on past prices and says nothing about future direction.
  • Volatility: sample standard deviation of daily simple returns over the displayed period (percent). It describes past variability only.
  • Volume / market cap: a rough activity ratio. It can be distorted by inflated or wash-traded volume and is not a valuation measure.

Rankings and screening

Most actively traded ranks assets by descending 24-hour USD volume, excluding assets with missing volume. The Potential-opportunity screen includes assets only when all user-set thresholds pass: minimum 24-hour percentage change, minimum volume-to-market-cap ratio, and minimum market cap. The screen reports measurable metrics; it is not a recommendation or a prediction.

Limitations

  • Forecasting and backtesting are not implemented; the site makes no predictions.
  • Public API data can be delayed, rate-limited, temporarily unavailable, or different from another provider.
  • The watchlist is stored only in the current browser using local storage. Clearing browser data removes it.
  • The history display is daily-sampled data and is not intended for execution or high-frequency trading.
  • Educational use only; not financial advice.
